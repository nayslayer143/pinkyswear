Connect Google sign-in

Google sign-in uses Google Identity Services with an OAuth Web client. PinkySwear only requests basic account identity; it does not need a Google API key or client secret.

  1. Open Google Cloud Console and create or select a project.
  2. Configure the OAuth consent screen / Google Auth Platform branding and audience for your app.
  3. In APIs & Services → Credentials, choose Create credentials → OAuth client ID → Web application.
  4. Add each exact site origin under Authorized JavaScript origins (scheme, hostname, and port only; no path), including the published PinkySwear origin and any preview or development origin you use.
  5. Copy the OAuth client ID ending in .apps.googleusercontent.com into the field below and select Save API settings. Reload the landing page to display Google’s sign-in button.
